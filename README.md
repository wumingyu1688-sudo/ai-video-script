# AI短视频剧本创作（ai-video-script）

一个 Claude 技能（Skill）：通过多轮对话，把一个初步创意逐步打磨成可定稿的 AI 短视频剧本（Word 文档）。适用于搞笑、剧情、科普、广告等各类短视频。

## 流程

1. **创意澄清**：确认平台与画幅、时长、基调、人物设定
2. **结构搭建**：开场钩子 → 主体逐级加码 → 高潮 → 结尾，首尾呼应
3. **分段打磨**：一次一段，每次 2–3 个方案并标出推荐；可选用经典影视画面与台词制造“熟悉又陌生”的感觉
4. **四维诊断**：从欢乐、知识、共鸣、节奏四个维度分析，给出前三条修改优先级
5. **定稿出剧本**：生成纯剧本 Word 文档，每次修改另存为新版本

贯穿全程：先给方案、确认后再动手；记住用户否掉的元素；不预设个人偏好。

## 安装

- **Claude 桌面版 / Claude.ai**：下载本仓库中的 `ai-video-script.skill`，在对话中打开并点击“保存技能”；或在设置的技能页面上传。
- **Claude Code**：把 `SKILL.md` 放到 `~/.claude/skills/ai-video-script/SKILL.md`。

## 使用

在对话里说“我想做一个 AI 短视频剧本”，再讲讲你的初步想法即可。
